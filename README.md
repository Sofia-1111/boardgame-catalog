## Лабораторна робота №15: Безпека клієнтських застосунків

### 1. Пошук та аналіз місць використання innerHTML (Крок 1)
* **Глобальний аудит коду:** За допомогою пошуку в редакторі за ключовим словом `innerHTML` з'ясовано, що прямих викликів `.innerHTML = ...` чи методів `insertAdjacentHTML()` у JS-коді немає.
* **Аналіз шаблонів Vue 3:** Усі динамічні дані користувача (`title`, `description`, `genre`) виводяться через стандартну текстову інтерполяцію `{{ title }}`. Vue 3 за замовчуванням трактує ці дані як безпечний текст (аналог `textContent`), що унеможливлює автоматичне виконання HTML/JS-коду.
* **Використання v-html:** Директива v-html використовується свідомо та контрольовано в компоненті GameCard (<h3 v-html="title"></h3>) для рендерингу заздалегідь екранованих даних через escapeHtml().
